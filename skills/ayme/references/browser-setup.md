# Browser setup

Set the project up for the `ayme` command as
[Set up your project](https://github.com/ayme-labs/ayme/blob/main/docs/guide/guides/connect-an-agent.md#set-up-your-project)
describes. Ask the user before you install, remove or change a package. When
a Session does not start, the command says why: find the message in
[Troubleshooting](https://github.com/ayme-labs/ayme/blob/main/docs/guide/troubleshooting.md#the-agent-cannot-reach-the-page),
fix it, and start the Session again.

Then check the setup end to end: start a Session beside your browser
automation, as [Browser automation tools](browser-automation-tools.md) says,
run one of the project's Page Object Tools with `ayme call`, and confirm its
visible effect with your browser automation.
