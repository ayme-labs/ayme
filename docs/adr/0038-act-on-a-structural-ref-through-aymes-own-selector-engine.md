# Act on a Structural Ref through ayme's own selector engine

A Structural Ref names a node of ayme's capture, and the capture maps every ref it prints to a DOM element. An action tool reached that element through Playwright's own ref selector, which Playwright resolves only for refs it minted in its own latest snapshot. That made Playwright a second owner of the lookup, and it disagreed with ayme's in two ways: a synthetic ref, which ayme gives a Page Object Root whose element Playwright's snapshot left without a ref, could be observed but not acted on, so every single-element tool refused it, while a collection Page Object Tool allowed it by a policy of its own; and a ref printed for an element that receives no pointer events found nothing, because the re-snapshot taken before the action minted no ref for it. Continuity between refs belongs to the observation session's identity ledger (ADR-0028); acting on the element a ref names belongs to ayme. We decided that ayme registers its own selector engine through Playwright's public selector registration, resolving a ref from the current capture's ref-to-element map; action tools run a locator on that engine like any other locator, Playwright's actionability checks stay, and core's Structural Ref grammar writes and reads the new selector in the one place that owns it. Every ref a capture prints resolves through the engine, synthetic or real, so no tool refuses a ref for being synthetic, the resolver has no synthetic policy, and no tool takes a second Playwright snapshot before acting (the capture the Page State Session takes to resolve a ref against its identity ledger stays, as ADR-0028 requires). Which refs a tool offers no longer depends on which refs Playwright minted; a Browser Tool still offers only the elements its input would reach (ADR-0062), and a Page Object Tool picks its instance by Page Object Id, not by ref (ADR-0063). Playwright, playwright-lite included, learns nothing about Page Objects: the engine takes a ref and returns an element. playwright-lite calls a function engine as it is, in the page's one JavaScript world, rather than evaluating its source, which a Content Security Policy that forbids evaluation refuses; so the engine keeps its module in scope and registers on any page ayme runs on. Because the engine reads the latest capture, a synthetic ref stays with its root element across the captures of a Page State Session, recorded ones and the Inspector's looks alike, as Playwright keeps a real ref with its element; a ref printed before a capture that intervened, such as an action's own before capture, still finds its element. We rejected giving roots real refs through a fork option that keeps elements ayme names, because it needs a fork tag and repin for every change and leaves the lookup tied to whatever Playwright's second snapshot mints; and keeping the refusal with one shared wording, because it reworded a limitation instead of removing it. The cost is that a locator carrying a Structural Ref is now resolvable only where ayme's runtime is loaded, which is already the only place such a locator is valid.
