# Act on a Structural Ref through Ayme's own selector engine

A Structural Ref names a node of Ayme's capture, and the capture maps every ref it prints to a DOM element. Until now an action tool reached that element through Playwright's `aria-ref=` selector, which Playwright resolves only for refs it minted in its own latest snapshot. That made Playwright a second owner of the lookup, and it disagreed with Ayme's in two ways: a synthetic `s_…` ref, which Ayme gives a Page Object Root whose element Playwright's snapshot left without a ref, could be observed but not acted on, so every single-element tool refused it and generate_locator refused it in its own words, while a collection Page Object Tool, whose root may carry one, allowed it by a policy of its own; and a ref printed for an element that receives no pointer events found nothing, because the re-snapshot taken before the action minted no ref for it. We decided that Ayme registers its own selector engine, `ayme-ref`, through Playwright's public `selectors.register`, resolving a ref from the current capture's ref-to-element map; action tools run `page.locator("ayme-ref=e5")` like any other locator, Playwright's actionability checks stay, and core's Structural Ref grammar writes and reads the new selector in the one place that owns it. Every ref a capture prints is actionable by every tool, so no tool refuses a synthetic ref, the resolver has no synthetic policy, no tool takes a second Playwright snapshot before acting (the capture the Page State Session takes to resolve a ref against its identity ledger stays, as ADR-0028 requires), and the set of refs a tool offers is decided by its element filter alone. Playwright, playwright-lite included, learns nothing about Page Objects: the engine takes a ref and returns an element. playwright-lite calls a function engine as it is, in the page's one JavaScript world (fork tag `ayme-2026-10-14` evaluated its source, which a Content Security Policy without `unsafe-eval` refuses; `ayme-2026-10-16` calls it), so the engine keeps its module in scope and registers on any page Ayme runs on. Because the engine reads the latest capture, a synthetic ref stays with its root element across the captures of a Page State Session, recorded ones and the Inspector's looks alike, as Playwright keeps a real ref with its element; a ref printed before a capture that intervened, such as an action's own before capture, still finds its element. We rejected giving roots real refs through a fork option that keeps elements Ayme names, because it needs a fork tag and repin for every change and leaves the lookup tied to whatever Playwright's second snapshot mints; and keeping the refusal with one shared wording, because it reworded a limitation instead of removing it. The cost is that a locator carrying a Structural Ref is now resolvable only where Ayme's runtime is loaded, which is already the only place such a locator is valid.

This decision amends ADR-0028: continuity between refs still belongs to the observation session's identity ledger; acting on the ref the ledger resolves to belongs to Ayme's engine.
