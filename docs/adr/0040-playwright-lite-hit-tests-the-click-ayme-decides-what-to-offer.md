# Playwright Lite hit-tests the click, and Ayme decides what to offer

ADR-0035 and ADR-0039 measure whether a click would reach a Page Object Root or an element a Browser Tool addresses with Ayme's own hit testing: nine sampled points over the part of the element a simulated scroll would show, an ancestor hit taken as evidence of reach, and a walk of the composed tree for descendants that take pointer events. The click itself is Playwright Lite's, which scrolls the element into view for real, then hit-tests one point, the centre of the first of its boxes the viewport shows. The two drifted: a button covered only at that centre was offered and the click timed out (ayme-labs/ayme#828), and the simulated scroll kept sprouting cases, slot fallback text, closed shadow roots, hidden SVG, that the browser's own click never asked about. We keep the division of labour and move the hit test: Ayme still decides what to offer and refuses fast with an Availability Reason, and Playwright Lite's `internal` entry answers, for one element and without scrolling, waiting or input, the one point its click would use and what a click there would hit instead, through open shadow roots and the closed ones it has learned, with its own button-link retargeting. An element whose click point lies in a part of it shown now is available iff that answer names nothing in the way, and the reason names what it does, as before, walked up to the first element the agent's page state gave a ref; Ayme's own Inspector is never in the way, because it lets a runtime action through. An element whose click point shows nowhere now, as when it lies below the fold or scrolled out of its container, but which would show once its scroll containers and the viewport scrolled to it, is present and offered without a hit test, and Ayme keeps only as much scroll simulation as answers that question; one that would show nothing even then, clipped by overflow, with no box or not displayed, stays absent. A call that clicks, a Browser Tool's or a Page Object Tool's, runs the same test where the click will land: when the click point shows nowhere now, the call first scrolls the element into view through Playwright Lite's own scroll, which is no Interaction of the agent, then tests the one point and refuses at once with the usual reason. An open native modal the element is not in, or an inert ancestor, blocks it as before, and keyboard input still asks only that. We considered keeping Ayme's sampler and teaching it each new case, rejected because every case it learns is one more place to drift from the click; running Playwright Lite's full trial click per candidate, rejected because it scrolls the page for real and waits per element, which an offering pass over every candidate cannot afford; and hit-testing at the position a simulated scroll projects, rejected because it is the simulation whose cases kept growing. The cost is that an element below the fold covered where it will land is found at call time, not when it is offered, and that a Page Object Root below the fold reads as available until a call scrolls to it.

This decision amends ADR-0035 and ADR-0039.
