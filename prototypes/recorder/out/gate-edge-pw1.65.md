# Gate edge cases on Playwright 1.65

`same` means the page ended in the same state and the recorder recorded the same actions as with no gate.

| case                                               | no gate: state / recorded                      | gate A                                                             | gate B                                                             |
| -------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------ |
| plain click                                        | 1 / click                                      | same: 1 / click [gate]                                             | same: 1 / click [gate]                                             |
| double-click                                       | doubled / click x2                             | same: doubled / click x2 [gate]                                    | same: doubled / click x2 [gate]                                    |
| drag and drop (HTML5 draggable)                    | dropped / nothing                              | **differs**: drop zone / click [gate]                              | same: dropped / nothing                                            |
| text selection by dragging                         | ome selectable text for / click                | **differs**: / click [gate]                                        | same: ome selectable text for / click [gate]                       |
| custom slider (pointer events)                     | 110 / click                                    | **differs**: 0 / click [gate]                                      | same: 110 / click [gate]                                           |
| native range slider                                | 10 / fill "10"                                 | same: 10 / fill "10" [free-before]                                 | same: 10 / fill "10" [free-before]                                 |
| native select (keyboard typeahead)                 | c / press c, select ["c"]                      | same: c / press c [gate], select ["c"] [free-before]               | same: c / press c [gate], select ["c"] [free-before]               |
| native select (mouse opens the list)               | mousedown:pick click:pick:1 / press Escape     | same: mousedown:pick click:pick:1 / press Escape [gate]            | same: mousedown:pick click:pick:1 / press Escape [gate]            |
| file chooser                                       | C:\fakepath\a.txt / fill "C:\\fakepath\\a.txt" | same: C:\fakepath\a.txt / fill "C:\\fakepath\\a.txt" [free-before] | same: C:\fakepath\a.txt / fill "C:\\fakepath\\a.txt" [free-before] |
| right-click                                        | context menu / click right                     | same: context menu / click right [free-before]                     | same: context menu / click right [free-before]                     |
| link that opens a new tab                          | /two; opener still at /edge / click            | same: /two; opener still at /edge / click [gate]                   | same: /two; opener still at /edge / click [gate]                   |
| click inside an iframe                             | 1 / click                                      | same: 1 / click [gate]                                             | same: 1 / click [gate]                                             |
| click inside an iframe, page scrolled              | 1 / click                                      | same: 1 / click [gate]                                             | same: 1 / click [gate]                                             |
| click that navigates, then a click on the new page | /two / click, click                            | same: /two / click [gate], click [gate]                            | same: /two / click [gate], click [gate]                            |
| click on a label of a checkbox                     | true / click, check                            | same: true / click [gate], check [free-before]                     | same: true / click [gate], check [free-before]                     |
| menu that opens on pointerdown                     | true / click                                   | same: true / click [gate]                                          | same: true / click [gate]                                          |
| Enter on a focused button                          | 1 / press Enter, click x0                      | same: 1 / press Enter [gate], click x0 [free-before]               | same: 1 / press Enter [gate], click x0 [free-before]               |
| typing, then Control+a                             | ab / click, fill "ab", press a                 | same: ab / click [gate], fill "ab" [free-before], press a [gate]   | same: ab / click [gate], fill "ab" [free-before], press a [gate]   |
| shift+click                                        | 1 / click                                      | same: 1 / click [gate]                                             | same: 1 / click [gate]                                             |
