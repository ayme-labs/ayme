# @ayme-dev/e2e

An internal prototype of [Ayme](https://github.com/ayme-labs/ayme): Ayme page objects as tools for [tester-army/e2e](https://www.npmjs.com/package/e2e), a step executor that answers page object steps from a call store before asking a coding agent over the Agent Client Protocol, and that store. It is research code, private to this repository, and not published.
