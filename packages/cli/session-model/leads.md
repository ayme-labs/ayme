# Lead ledger

Leads from the rules agreed for the second round (2026-11-26) and the
runtime pieces the Session reuses. Each ends as a checker finding, a
question, a design finding the model cannot express, or cleared.

| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A Tab hidden in the middle of a Run (window minimised, Tab switched, or a popup the Run opened taking the front)                                                                           | stuck state     | checker: `HiddenMidRun_*` broken where hidden page work stalls; holds where it finishes. No rule yet                                                                       |
