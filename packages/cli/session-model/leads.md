# Lead ledger

Leads from the agreed rules, the spike's background process
(`origin/t3/node-cli-page-object-spike`, `packages/mcp/src/node-session/`) and
the runtime pieces the session reuses. Each ends as a checker finding, a
question or cleared.

| Lead                                                                                                                                              | Kind                   | Outcome                                                                                                                                     |
| ------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| A call is answered early (dialog, hidden tab) but its Playwright action keeps the page's turn (`packages/ayme/src/runs/application/run.ts:85-91`) | event order, lifecycle | checker: `R1_AgentRequestAnswered` broken via a listing queued behind it on a hidden tab; `R5_NoSwapDuringCall` broken via a swap during it |
| Swap gated on the session's own requests versus on the page's turn                                                                                | check then act         | checker: the strict gate makes rule 5 hold and `R5_RebuildIsSwappedIn` break (variant run, not kept)                                        |
| A listing after a failed build while the next rebuild runs                                                                                        | unhandled state        | checker: `R6_ListingSaysBuildFailing` broken                                                                                                |
| Page Object ids are counted per page (`packages/ayme/src/page-objects/application/pageObjectIds.ts:16-70`)                                        | stale copies           | checker: `R7_UniqueAcrossTabs_RuntimePerPageCounter` broken                                                                                 |
| A new session restarts the id counter                                                                                                             | stored state           | checker: `R7_NotReusedAfterRestart` broken; question whether rule 7 spans sessions                                                          |
| A pick starts after its window closed (the start crosses an await)                                                                                | check then act         | checker: `R11_PickNeverOutlivesWindow` broken                                                                                               |
| Two calls from two callers on one tab                                                                                                             | event order            | cleared in the model by the shared per-page queue (`packages/ayme/src/runtime/session.ts:593`): `R4_OneCallPerPage` holds                   |
| Requests pending when the browser goes away or the session stops                                                                                  | stuck state            | cleared in the model: the end answers them; holds under `R1_*`                                                                              |
| Two starts before either writes the record (the spike writes it after it listens: `background.ts`, `writeRecord` at the end of `runBackground`)   | check then act         | question: the model treats check and claim as one step                                                                                      |
| First build fails, so there is no last good build                                                                                                 | unhandled state        | question; the spike refuses to start                                                                                                        |
| `ayme close` after `ayme detach` from a browser ayme started                                                                                      | lifecycle              | question: `Q_OwnBrowserLeftWithoutSession` reachable                                                                                        |
| The working tab, or a tab whose ids an agent holds, closes                                                                                        | unhandled state        | question: not modelled (the spike ends the session when its page closes)                                                                    |
| Playwright dismisses a dialog itself when the page has no `dialog` listener                                                                       | hidden mode            | not checked: outside the model; rule 3 needs a listener that never answers                                                                  |
